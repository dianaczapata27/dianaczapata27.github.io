Once the density field was reconstructed, we used the DisPerSE code to extract and visualize the filaments that trace the large-scale structure of the Universe.

Effect of smoothing

We tested three smoothing scales (5, 7, and 10) and found that higher smoothing produces fewer, longer filaments, highlighting the main “super-filament” backbone while removing small-scale structure. For the rest of the analysis, we adopt the intermediate value (7 Mpc) as a balance between detail and large-scale coherence.

Large-scale structure

This figure shows the filamentary network for the sample (Mi ≤ -23) (G < 20.5), where the characteristic pattern of the cosmic web becomes evident: a coherent mesh of interconnected filaments tracing the main axes of overdensity in the volume.

Filament occupation

The occupation of a filament is defined as the number of quasars associated with it, where each quasar is assigned to the filament for which the distance between the quasar and the filament's axis is the smallest.
